Completed the upload and download of files using Cloudflare R2.

used chunking to upload files and download files.

solved the issue i am having for 1 year. 

Required environment variables:

- `R2_BUCKET_NAME`
- `R2_ACCESS_KEY_ID`
- `R2_SECRET_ACCESS_KEY`
- `R2_ACCOUNT_ID` or `R2_ENDPOINT_URL`
- Optional: `R2_PUBLIC_BASE_URL` for public object URLs in upload responses.
